# Datasets

Synthetic plans from `tools/make_synthetic_plan.py` are the only plans in git. `samples/blueprints/office_vector/plan.pdf` is the clean vector demo. `samples/blueprints/office_raster/plan.png` is the same sheet rendered with a small rotation, blur, and JPEG compression so the raster path has a committed input. Both are generated by this repo and carry no third-party license.

`scripts/download_samples.py` writes into `data/`, which is gitignored.

| Dataset | License | Commercial use | Notes |
| --- | --- | --- | --- |
| CubiCasa5K | Creative Commons Attribution 4.0 | Yes, with attribution | The script records the project page only. Images and weights are not in this repo. |
| buildingSMART sample IFC | Check the file's own header; samples are generally open | Usually yes | Download returned HTTP 404 for the Duplex path that used to be in Sample-Test-Files. Not committed. |
| Public fire-evacuation PDF | Would have been recorded here | Unknown until a file is obtained | The NYC FDNY URL tried by the script returned HTTP 403. Not committed. |

Non-commercial datasets will be flagged here before use. None are in use.
